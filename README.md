# Aerial releases

Installers and release notes for **Aerial**, a desktop app for live TV, radio and public-domain films.

The app checks this repository's latest release to offer updates; its source code is kept elsewhere.

- **Already have Aerial?** Download `Aerial-Update-<version>.exe` from the [latest release](https://github.com/topspeed242-del/aerial-releases/releases/latest). It replaces the app's files and keeps your favourites and settings. Aerial also offers it by itself when a new version is out.
- **New install:** download `Aerial-Setup-<version>.exe` from the same page.

Windows 10/11, 64-bit.
